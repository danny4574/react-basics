# My First React App

A small interactive React app built to practise components, JSX, props, state, events and conditional rendering.

## What it does
- Shows the heading "My First React App" and a short intro about me
- Counter that starts at 0 with Increase, Decrease and Reset buttons
- Shows "Even number" or "Odd number" under the counter
- Name input that shows "Hello, [name]! Welcome to my React app." only when something is typed (greeting is a lighter red)
- Footer with the current year

## Concepts used
Functional component, JSX, `useState`, `onClick`, `onChange`, conditional rendering.

## How to run locally
```bash
npm install
npm run dev
```
Then open the local link shown in the terminal (usually http://localhost:5173).
